这个站怎么来的

源文件是 org,由 Emacs 的 org-publish 导出成静态 HTML,托管在 GitHub Pages。 仓库在 jamesarch/jamesarch.github.io。

构建是确定性的:同一份 org 在任何机器上产出逐字节相同的 HTML,CI 用 git diff --exit-code 就能校验产物与源同步。代码块的配色取自 doom-themes 的 doom-one 与 doom-one-light, 跟随系统深浅色切换。
